# T-202 검증기 입력 명세 보완 제안

상태: 제안. 승인된 명세가 아니며 안전 규칙이나 초기값을 변경하지 않는다.

`ValidateInput`은 현재 계획과 오늘 날짜만 받는다. 이 정보만으로는 PRD §7.4의 모든 규칙을 검증할 수 없다. 검증 불가능한 규칙을 통과로 처리하면 `TE-S12`를 지킬 수 없으므로, 구현 전에 아래 입력과 판정 방식을 명세에 추가할 것을 제안한다.

| 규칙 | 부족한 정보 또는 결정 | 보완 제안 |
|---|---|---|
| `TE-S09` | 변경 전 주간 거리와 놓친 훈련 | 변경 전 계획과 변경 대상·사유를 검증기에 전달하고 변경 전후 주간 거리와 훈련 배치를 비교한다. 놓친 훈련을 몰아 보충하는 행위의 판정 기준도 정한다. |
| `TE-S10` | 마지막 운동 기록 날짜와 복귀 전 훈련량 | 실제 기록 날짜와 이전 계획을 전달하고, 기록 부재의 의미와 감량 판정 기준을 정한다. 계획 재계산 제안 자체는 검증기의 통과·위반 결과만으로 표현할 수 있는지도 결정한다. |
| `TE-S11` | 변경 사유와 변경 전 훈련량·강도 | 변경 사유와 변경 전 계획을 전달하고, 세션별 또는 주간 단위로 양·강도를 비교할지 정한다. |
| `TE-S14` | 걷고 달리기 훈련의 달리기 구간 길이와 이전 시간 기반 주간 총시간 | 구간 길이와 이전 시간 기반 주의 총시간을 전달한다. `continuousRun`은 범주형이므로 각 범주가 보장하는 시간 기준도 정한다. |
| `TE-S13` | 최근 30일의 계획 시작 전 달리기 이력 | 계획 시작 전 비교 이력을 어떤 입력으로 전달할지 정한다. 실제 기록이 계획보다 짧은 경우에는 2026-11-16 결정대로 별도 예외를 적용하지 않는다. |
| `TE-S02`, `TE-S08` | 회복 주의 식별, 부분 주·대회 전 감량 계산 기준 | 회복 주를 명시하거나 판정 방법을 정의하고, 부분 주와 대회가 없는 계획의 적용 범위를 정한다. |

`TE-S12`는 검증 실패 결과를 저장·제안하지 않는 호출 측 책임이다. 검증기 자체의 위반 규칙으로 보고할지 여부와 호출 측 검증 시점을 명세에 분명히 한다.

제안된 입력은 생성·변경·승인 경로에서 동일한 기준으로 제공되어야 한다. 정보가 없을 때는 검증 불가를 안전하게 반환하도록 결과 형식도 정한다. 위 내용은 구현 방향을 검토하기 위한 제안이며, 결정 전에는 기존 `ValidateInput`을 임의로 확장하거나 규칙의 빈 부분을 추정하지 않는다.
