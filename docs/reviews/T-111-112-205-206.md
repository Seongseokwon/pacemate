# T-111·T-112·T-205·T-206 교차 검토

대상: PR #43이 병합된 `79717ac`. PRD §11의 관련 인수 기준과 연결된 앱·API 코드를 확인했다. 기기 실행과 인증 서비스 연결은 확인하지 않았다.

## 수정이 필요한 사항

1. **계획 확정 직후 앱이 종료되면 알림 권한 화면을 건너뛴다** (`T-111`, F09-R03). `apps/mobile/src/app/(onboarding)/plan-preview.tsx`의 확정 요청은 서버에 계획을 저장한 뒤에야 `advance('planConfirmed')`를 호출한다. 그 사이 앱이 종료되면 다음 실행에서 `afterPlan`이 비어 있고 서버에는 활성 계획이 있어 `firstRunRoute`가 홈으로 보낸다. 계획 확정과 권한 안내를 복구할 수 있는 상태를 남겨 재실행 시 이어야 한다.

2. **훈련 상세에서 기록 입력이 열리지 않는다** (`T-205`, AC-F06-03). `apps/mobile/src/components/session-detail.tsx:94`는 훈련 날짜와 ID를 기록 탭에 넘기지만, `apps/mobile/src/app/(tabs)/records.tsx`는 전달된 값을 읽지 않아 목록만 연다. 홈의 오늘·어제 기록하기도 같은 경로다. 기록 탭에서 전달값을 소비해 해당 날짜와 훈련이 선택된 입력 화면을 열어야 한다.

3. **다른 기기에서 만든 계획을 현재 미리보기의 성공으로 처리한다** (`T-205`, F03-R05). 미리보기를 연 뒤 다른 기기에서 다른 계획을 확정하면 서버는 `PLAN_ALREADY_ACTIVE`를 반환한다. `apps/mobile/src/app/(onboarding)/plan-preview.tsx:55`는 이를 무조건 성공으로 처리해 답변을 지우고 완료 흐름으로 이동한다. 기존 계획이 이번 요청으로 만든 계획인지 확인할 수 없으므로 오류와 현재 계획을 안내해야 한다.

4. **기기 시간대가 한국과 다르면 캘린더의 오늘이 서버와 다르다** (`T-205`, AC-F06-01). `apps/mobile/src/ui/dates.ts:13`은 기기 현지 날짜를 쓰지만 서버의 훈련 상태는 한국 날짜를 쓴다. 해외 체류 중 한국과 날짜가 다른 시각에는 캘린더의 오늘 표시와 처음 선택한 날짜가 어긋난다. 화면의 오늘도 한국 시간대로 계산해야 한다.

## 나머지 확인 결과

- `T-111`: 인트로와 온보딩 연기 경로는 상태 전이 및 저장 테스트가 있다. 실제 로그인 이후 흐름과 기기 재실행은 인증 연결 후 확인이 필요하다.
- `T-112`: 다크 모드 고정, 토큰·아이콘 교체와 대비 테스트를 확인했다. 네이티브 빌드의 화면 비교는 B-15·B-16에 남아 있다.
- `T-205`: 주간·월간 조회, 상태와 변경 전 일정의 표시 코드를 확인했다. AI 코치 연결은 T-408이 필요하다.
- `T-206`: 목표 없음의 질문 분기, 서버 검증, 9주 기초 계획과 불변식 테스트를 확인했다. 별도의 수정 사항은 찾지 못했다.

판정: 위 네 항목을 해결한 뒤 해당 인수 기준을 다시 확인한다. 본 검토는 코드를 수정하지 않았다.
